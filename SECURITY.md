# Security Policy

PIPPA is a personal showcase prototype built with fictional policies and synthetic company data. It is not intended for real operational, legal, financial, employment, or customer decisions.

## Supported version

Security reports should relate to the current `main` branch or the hosted showcase linked from this repository. Older snapshots are not supported.

## What to report

Reports may cover authentication or access-control weaknesses, exposure of another user's information, injection or unsafe input handling, vulnerable dependencies, and other security problems in the published source or hosted showcase.

Policy-answer disagreements, feature requests, and vulnerabilities that belong solely to GitHub, Streamlit, Supabase, Cloudflare, or another third-party service are outside this project's security scope. Report third-party vulnerabilities directly to the relevant provider.

## Report a vulnerability privately

Do not disclose a suspected vulnerability, exploit, credential, personal information, or access-control detail in a public issue, discussion, pull request, or social-media post.

Use GitHub's private vulnerability-reporting option from this repository's **Security** tab when it is available. If that option is not shown, open a public issue titled **Private security contact requested** without including technical details, and wait for the repository owner to provide a private reporting route.

Please include, through the private channel:

- a clear description of the suspected issue and its potential impact;
- the affected page, component, or source file;
- safe reproduction steps using only fictional data and an account you control; and
- screenshots or logs with credentials, tokens, email addresses, and other personal information removed.

## Safe testing boundaries

- Use only your own test account and fictional information.
- Do not attempt to access, modify, export, or delete another person's data.
- Do not use high-volume automated testing, denial-of-service techniques, social engineering, or credential attacks.
- Do not test third-party services beyond the normal PIPPA user flow.
- Stop testing if you encounter information that may belong to another person and report the issue privately.

## Response and disclosure

I aim to acknowledge a valid report within seven calendar days. Investigation and resolution times will depend on severity and complexity. Please allow time to investigate before any public disclosure.

Reports will be reviewed on a reasonable-effort basis. This showcase does not operate a paid bug-bounty programme.
